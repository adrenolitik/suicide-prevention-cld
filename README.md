## 📂 Каталог исследований: «Суициды» (ГомГМУ, БелЖД, ГОКПБ)

В платформу интегрирован доказательный триптих суицидологических исследований с полной оцифровкой причинно-следственных связей, контуров обратной связи и математических моделей:

### 🎯 Проект 1. Меры по совершенствованию оказания помощи в профилактике самоубийств (2025–2030 гг.)
* **Авторы:** Е. Н. Щербакова, Т. М. Шаршакова, А. А. Ковалев, А. В. Чистов.
* **Публикация:** *Проблемы здоровья и экологии / Health and Ecology Issues.* 2025; 22(2): 112–120. **DOI:** [10.51523/2708-6011.2025-22-2-13](https://doi.org/10.51523/2708-6011.2025-22-2-13).
* **Суть:** Доказательное обоснование 10-компонентного межведомственного алгоритма (здравоохранение, МВД, комитет по труду и соцзащите, управление образования, Советы по демографической безопасности).
* **Ключевые инновации:**
  1. Обязательный ежегодный скрининг взрослого населения по методике **ASQ (*Ask Suicide-Screening Questions*)** по Приказу МЗ РБ от 26.02.2025 № 194 при диспансеризации и в приемных покоях стационаров.
  2. Развертывание кабинетов психологов во всех ведомствах профилактики (МВД, соцзащита, образование).
  3. Восстановление формы Извещения о парасуициде (приказ № 699) для сквозного учета попыток.
  4. Линейное моделирование в R 4.5.0:
     $$Y_{\text{без ПМ}} = 917{,}61 - 0{,}45 \times \text{год} \quad \text{vs} \quad Y_{\text{с ПМ}} = 1231{,}72 - 0{,}60 \times \text{год}$$
     Ускорение темпа снижения на **33.3%** с выходом на целевой уровень **10.02 на 100 тыс. к 2030 г.**
  5. Подтвержденный эффект в районах: Ельский ($RR = 0.695, p = 0.014$), Житковичский ($RR = 0.776, p = 0.001$), Речицкий ($RR = 0.870, p = 0.013$), Кормянский ($\chi^2 = 14.63, p = 0.012$).

### 📈 Проект 2. Анализ суицидальной активности населения Гомельской области (2018–2024 гг.)
* **Авторы:** Е. Н. Щербакова, Т. М. Шаршакова, А. А. Ковалев.
* **Публикация:** *Проблемы здоровья и экологии.* 2025; 22(1): 102–111.
* **Выборка:** $N = 1449$ протоколов межведомственного разбора случаев смерти от суицида.
* **Эпидемиологический портрет:** 
  * Мужчины — **83.09%** (1204 чел.), средний возраст $51.2$ года (51.1% трудоспособные);
  * Без постоянной работы — **47.26%**, одиноко проживающие — **31.19%**;
  * Тяжелая алкогольная интоксикация ($>1.5‰$ этанола) — **27.34%**;
  * Институциональная невидимость: **86.21%** не состояли на учете у психиатра, **80.13%** — у нарколога;
  * Скрытый пресуицид: в **73.20%** отсутствовали высказывания, в **81.25%** суицид был первичным без попыток в анамнезе;
  * Высоколетальные методы: повешение/удушение у **84.41%**.

### 🎗️ Проект 3. Организационно-медицинские барьеры в профилактике суицидов
* **Авторы:** Е. Н. Щербакова, Т. М. Шаршакова, А. А. Ковалев.
* **Публикация:** *Проблемы здоровья и экологии.* 2024.
* **Выборка:** $N = 491$ врач соматического профиля (ВОП, терапевты, хирурги, неврологи, организаторы).
* **Ключевые барьеры:** 
  * Когнитивные мифы врачей: 70.1% убеждены, что желающие умереть не говорят об этом; 49.1% считают высказывания лишь «привлечением внимания»; 52.3% считают мысли редкими;
  * Дефицит времени на приеме и страх ятрогении («спровоцировать суицид вопросом»);
  * Трехуровневая модель превенции (первичное звено $\rightarrow$ специализированная помощь $\rightarrow$ межведомственная координация).

## 🚀 Как сделать форк и развернуть веб-приложение на GitHub

### Автоматический деплой на GitHub Pages (Standalone Web App)
В репозиторий уже добавлен рабочий пайплайн **GitHub Actions** (`.github/workflows/deploy.yml`).

Чтобы ваше веб-приложение стало доступно в интернете по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`:
1. Создайте репозиторий на GitHub (например, `omnicausal-suicide-prevention`).
2. В репозитории на GitHub перейдите в **Settings** $\rightarrow$ **Pages** $\rightarrow$ **Build and deployment** $\rightarrow$ выберите **Source: GitHub Actions**.
3. Отправьте код в ветку `main` (через экспорт AI Studio или `git push`).
4. GitHub Actions автоматически соберет проект и развернет живое веб-приложение!

---

### Способ 1: Прямой экспорт из Google AI Studio
1. В интерфейсе приложения откройте меню **Settings** (в правом верхнем углу).
2. Нажмите **Export to GitHub** (или **Download ZIP**).
3. Укажите имя нового репозитория на GitHub (например, `omnicausal-suicide-prevention`).
4. Все файлы, модели, диаграммы и конфигурация GitHub Pages будут автоматически перенесены в ваш аккаунт.

### Способ 2: Инициализация и пуш через Git CLI

```bash
# 1. Привязка вашего удаленного репозитория GitHub
git remote add origin https://github.com/<ваш-логин>/omnicausal-suicide-prevention.git
git branch -M main

# 2. Отправка изменений в ветку main (запустит автоматический деплой)
git push -u origin main

# 3. Локальный запуск (при необходимости)
npm install
npm run dev
```

## 🛠️ Архитектура и стек технологий

* **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Canvas Confetti.
* **Визуализация данных и графов:** Интерактивный каузальный холст (HTML5 Canvas + SVG), Recharts для симуляции временных рядов.
* **Backend:** Node.js Express (порт 3000), Vite Middleware.
* **ИИ-агент:** Google GenAI SDK (`@google/genai`), автономный научный цикл генерации гипотез, поиска контуров обратной связи и точек рычага Д. Медоуз.

## 📊 Структура каталога «Суициды» в кодовой базе

* `src/data/benchmarks.ts` — исходные модели трех исследований с узлами, матрицами весов, полярностями (`+` / `-`) и регрессионными уравнениями.
* `src/components/SuicideCatalogModal.tsx` — интерактивный браузер каталога с карточками проектов, метриками и экспортом.
* `src/components/CausalCanvas.tsx` — интерактивный граф причинно-следственной диаграммы (CLD) с подсветкой петель $R_1, B_1, B_2, B_3$.
* `src/components/SimulationPanel.tsx` — численная симуляция динамики системы при масштабировании скрининга ASQ и психологических кабинетов.
* `src/components/LeveragePointsPanel.tsx` — ранжирование точек вмешательства по шкале Донеллы Медоуз.
* `src/components/ScientificPaperView.tsx` — структурированный академический отчет с формулами и источниками.
